# LJT-Homepage

Personal academic homepage for **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

Website: https://emblemrookoutfit.github.io/LJT-Homepage/

This site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Repository structure

- `_pages/about.md` — about page: personal details, research interests, academic background, research experience, publications, skills, honors, and contact information
- `_pages/cv.md` — curriculum vitae
- `_pages/publications.html` — publications index page
- `_publications/` — individual publication entries
- `_data/navigation.yml` — top navigation links
- `_config.yml` — site-wide configuration and sidebar author profile
